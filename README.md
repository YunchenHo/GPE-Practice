# GPE Practice

Practice solutions and notes while I prepare for NYCU CS Department's programming proficiency exam (GPE, 程式能力檢定).

## Structure

- Individual `.cpp` / `.py` files, one per online judge problem, named `<problem ID>_<Problem Name>`.
- [`c++_method.md`](./c++_method.md) — a running reference of C++ STL containers, common pitfalls, and algorithm patterns I've picked up while solving these problems, organized by topic.

## Topics covered so far

- STL containers: `vector`, `list`, `string`, `pair`/`tuple`, `set`, `map`, `stack`, `queue`, `deque`
- Common pitfalls: `cin`/`getline` mixing, pointer vs. reference, pass-by-value vs. pass-by-reference
- Graph traversal: DFS (recursive & iterative), BFS, shortest path
- Tree traversal: preorder/inorder/postorder reconstruction
- Dynamic programming: basics, coin change, LIS/LCS, game DP

## Status

In progress — solutions and notes get added as I keep practicing for the exam.
